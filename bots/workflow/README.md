# Firstmate workflow

An optional skill for choosing among the four Bots and checking their results. Firstmate owns the final answer; the specialists are not mandatory stages.

[Source instructions](skills/use-four-bots/SKILL.md) · [Recorded routing checks](CHECKS.md)

## Setup

Add the complete `use-four-bots` skill to your existing coordinator without replacing its identity or permissions. Resolve the intended installed Bots before a handoff. Public template links identify the intended templates but do not install, connect, or grant access to them.

After setup, inspect the saved skill and available connections. If direct Bot messages are unavailable, the workflow prepares a handoff for you instead of pretending to delegate.

Try: "Use the four-bot workflow for this request. Choose only the helpers needed, check their answers, and give me the next action."

Simple tasks stay with the coordinator. Use First Principles for unclear framing, Product Ideation for product opportunities, Red Flag for a specific claim or artifact, and Garbage Collector for code complexity. Stop when the requested result is ready.
